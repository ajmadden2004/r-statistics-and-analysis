# r-statistics-and-analysis

This repository contains a collection of R scripts used for short examples and statistical analyses.

- Script_0115.R: R script with exploratory data analysis and example plots.
- Script_0120.R: R script focused on data cleaning and transformation steps.
- Script_0122.R: R script demonstrating basic statistical modeling (e.g., regressions).
- Script_0127.R: R script for data visualization and summary reporting.
- Script_0129.R: R script containing helper functions and reusable analysis snippets.
- Script_0203.R: R script with final analyses and consolidated results.
- Script_0210.R: R script with hypothesis testing and density plots.
- Script_0212.R: R script demonstrating two-tailed hypothesis testing and statistical inference.
- Script_0224.R: R script on nonparametric tests including Shapiro test and Q-Q plots for normality assessment.
- Script_0226.R: R script for grouped analysis and two-group comparison of life expectancy across continents.
- Script_0303.R: R script introducing simple linear regression with scatter plots and prediction.
- Script_0305.R: R script on simple linear regression, predictions, and equation interpretation.
- Script_0310.R: R script on regression diagnostics, Cook's distance, and influential case detection.
- Script_0312.R: R script on normality testing, density plots, Q-Q plots, and residual analysis for multiple variables.
- Script_0324.R: R script demonstrating different regression transformations (level-level, level-log, log-level, log-log).
- Script_0326.R: R script on residual analysis, diagnostic plots, and Box-Cox transformation for optimal lambda.
- Script_0409.R: R script on stepwise regression analysis and variable selection.
- Script_0414.R: R script on multicollinearity detection using VIF and best subsets regression with interaction terms.
- Script_0416.R: R script on time series regression with seasonal dummy variables and trend analysis.
- Script_0421.R: R script on ARIMA modeling and time series forecasting using auto.arima.
- Script_0423.R: R script on logistic regression for college admission prediction with binary outcomes.
- Script_0428.R: R script on multiple logistic regression and marginal effects analysis for graduate school admission.
